# NFC Platform

## Descripción

NFC Platform es una plataforma SaaS para la gestión de activos físicos mediante etiquetas NFC.

El primer módulo desarrollado será **Inmobiliaria**, aunque la arquitectura está diseñada para incorporar posteriormente otros sectores como:

- Restauración
- Hoteles
- Museos
- Industria
- Turismo

## Tecnologías

- Python
- Django
- SQLite (Desarrollo)
- PostgreSQL (Producción)
- Bootstrap 5

## Estado del proyecto

🚧 En desarrollo

Actualmente se encuentra en la fase de diseño y arquitectura.

## Arquitectura

El sistema está basado en un núcleo común compuesto por:

- Companies
- Accounts
- Assets
- Tags

A partir de este núcleo se desarrollan módulos específicos para cada sector.
